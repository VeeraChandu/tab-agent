Data & AI provider

When you run a task, the page content, screenshots, and tab details it needs are sent to the AI provider you configure in the Providers tab, using your own API key - that data goes directly from your browser to your chosen provider (Anthropic, OpenAI, or a compatible endpoint), never to Tab Agent's developer, because no server operated by the developer exists in this flow.

Everything else (API keys, chat history, custom agents, scheduled tasks, and settings) is stored only in this browser's local extension storage. It is never synced to Google or transmitted anywhere except as described above. See this extension's Privacy Policy (bundled with the extension, and linked from the Chrome Web Store listing) for the complete details.

How it works

Tab Agent reads the active tab's content and interactive elements, sends them to the model along with your task, and executes whatever action the model chooses (click, type, scroll, navigate, switch tabs) directly on the browser - no MCP server, no proxy, no extra setup.

Because the agent can click and type on pages on your behalf, review what it's about to do in the side panel log, and use Stop at any time.
